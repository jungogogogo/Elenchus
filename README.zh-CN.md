# decision-untangle

[English](./README.md) | 中文

一个给"没有选项就没法开始想"的人用的 Claude Skill——挖到你真正卡住的点，而不是简单甩个结论给你了事。

## 为什么做这个

我们这代人是被选择题喂大的：从小到大做题，几乎全是从ABCD里选一个。出了校门进入社会，突然被要求"独立思考""开放式思考"——没有选项，只剩一句"你怎么想"。很多人卡住的地方不是真的没有想法，而是缺一个能让自己开始想的具体选项——一旦有选项摆在眼前，反而能很快、很具体地说出自己想要什么、不想要什么，这是一种空气球式的开放提问永远激发不出来的清晰。

这个skill赌的就是这一点：大部分"想不清楚"不是思考能力问题，是缺脚手架。所以它不会让你凭空生成方向，而是先把脚手架搭好——具体选项，再配上结构化追问——然后才轮到你做决定。

## 这是什么

当你被一件"没想清楚"的事卡住时——不管是人生大事（换工作、去留、价值观排序），还是一个具体任务不知道怎么下手（怎么汇报、项目从哪开始）——这个skill会：

1. **先判断问题类型。** 如果你已经有具体选项或具体任务，直接进深挖；如果完全一团雾、连选项都说不出来，会先搭出3-4个具体候选方向，因为有东西可以反应，才是真正启动思考的钥匙。
2. **分两层深挖**，全程尽量用可点选的选项完成（`ask_user_input_v0`），不是甩给你一个空白输入框：
   - **事实层**——背景、受众、目的、现状。
   - **本质层**——至少一整轮，专门往下刨，找到你真正在纠结、不舒服、害怕的是什么。收口的标准不是"信息够了"，而是能不能填出这句话："你表面纠结的是___，但真正卡住的其实是___"，填不出具体答案就还没挖够。
3. **用"角色卡"的格式给结果**，不是一份分析报告：
   - **【LABEL】**——一个一针见血、带点玩梗的类型标签，只从这一次交互里提炼，风格类似MBTI。
   - 一段话讲清楚核心判断，同时带出优点、问题、当前状态。
   - 现在做什么 / 下一步 / 暂时别做什么。
   - 老老实实列出这一轮问了什么、你选了什么。

每次触发都是独立的一次分析——不引用历史对话或存下来的背景信息，因为用这个skill的不一定是同一个人。

## 怎么用

自然描述你卡在哪儿就行，或者直接触发：

```
/decision-untangle 该不该接这个offer
/decision-untangle 5    # 把深挖问题数量封顶在5个（默认不设死数，一般至少2轮，最多12个）
```

## 怎么装

1. 下载 [`decision-untangle.skill`](./decision-untangle.skill)（或者只拿 `decision-untangle/SKILL.md` 这一个文件）。
2. 在Claude里进 **设置 → Capabilities → Skills**（不同平台入口命名可能不太一样），上传这个文件。
3. 在任意对话里按上面的方式触发。
